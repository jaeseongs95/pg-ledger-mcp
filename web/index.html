소유자 관리자 콘솔 로그인

이 콘솔은 시스템 소유자(user:owner) 전용 제어 및 원장 관측 화면입니다.

보안 경계 안내
  • 서버 호스트의 /etc/<instance>/env에 기록된 PGLEDGER_ADMIN_TOKEN을 입력하세요.
  • 에이전트 클라이언트용 공유 토큰(DBHUB_AUTH_TOKEN)은 권한 상승 방지를 위해 거부됩니다.

MCP 확인 중...
권한 분리 원칙: 이 웹 콘솔은 소유자 제어(프로젝트·세션 권한·공통코드)와 원장 관측(Explorer) 전용입니다. 결함·과업 상태 전이(VERIFIED 등), 수정 커밋 등록(record_fix), 감사 이력 정정(correct)은 호스트 증명(_hostAttestation)과 세션 권한이 부여된 MCP 에이전트 세션에서만 수행됩니다.

트리아지 관심사 허브 (ledger.v_attention)

에이전트 협업 중 정체되거나 불변식 점검이 필요한 5대 이상 징후입니다. 카드를 클릭하면 해당 조건으로 즉시 필터링합니다.

결함 상태별 분포 (ledger.defect)

새 세션 권한 부여 (ledger.grant_session)

에이전트 세션에 프로젝트별 쓰기·검수 권한을 부여합니다. 동일 키의 기존 활성 권한은 안전하게 갱신됩니다.

빠른 접두사:
권한 범위 선택 (scope 매트릭스, 다중 선택 가능) *

세션 권한 목록 (ledger.session_grant)

권한 회수(Revoke) 시 실행 중인 에이전트의 쓰기 트랜잭션이 즉시 차단되므로 2단계 확인을 거칩니다.

ID 작성자 세션 (author_id) 프로젝트 범위 (scope) 상태 부여 시각 / 만료 시각 비고 제어
조회 중...
ID 프로젝트 심각도 분류 상태 제목 담당 세션 / 수정 세션 케이스 / 픽스 갱신 시각 상세

과업 목록 (ledger.task)

조회 중...
과업 ID 프로젝트 상태 제목 & 목적 완료 조건 (success_condition) 담당 / 생성자 연결 결함 / 조건 갱신 시각

릴리스 조건 목록 (ledger.condition)

조건 ID 프로젝트 릴리스 / 목표 코드 상태 조건 내용 연결된 과업 / 결함 갱신 시각

불변 감사 이력 (ledger.v_history)

PostgreSQL 트리거(history_no_update, history_no_truncate)로 보호되는 추가 전용(Append-Only) 감사 로그입니다.

조회 중...
이력 ID 시각 대상 엔티티 / ID 작업 (op) 상태 변화 작성자 / DB 로그인 사유 (reason) & 증빙 변경 내용 (changes)

새 프로젝트 등록 (ledger.project)

결함 채번 접두사(<CODE>-D-0001)와 과업 소속 단위가 되는 프로젝트를 등록합니다.

채번 예시: CODE-D-0001

등록된 프로젝트 목록

ID 채번 코드 제목 결함 (OPEN/전체) 과업 수 활성 권한 생성자

공통 코드 관리 및 DBHub 도구 정의 동기화 (ledger.common_code)

공통 코드는 과거 원장 참조 무결성(ledger._code_keep 트리거)을 위해 삭제하거나 코드명을 변경할 수 없으며, 비활성화(Retire)만 허용됩니다. 코드 저장 또는 활성/비활성 전환 시 /etc/<name>/dbhub.toml 재렌더링 및 DBHub 서비스 재시작이 자동 수행됩니다.
