# 사용자 가이드

[English](user-guide.md) · [문서 목차](guide.ko.md)

관리자 화면에서 프로젝트의 기록을 정리하고 진행 상황, 근거, 변경 이력을 확인합니다.

## 프로젝트와 버전

1. **프로젝트** 메뉴에서 고정 ID, 기록 ID 접두어, 표시 이름을 정해 프로젝트를 만듭니다. 이름과 설명은 **수정**에서 변경합니다.
2. 프로젝트의 바로가기에서 **프로젝트 버전**을 엽니다. 추적할 버전을 추가하고 해당 버전의 작업 공간을 엽니다.
3. 버전 작업 공간에서 명세·이슈·작업·출시 기준을 만들거나 기존 기록을 연결합니다. 연결을 해제하면 버전과의 연결만 풀리고 기록은 장부에 보존됩니다.
4. **개요**에서 프로젝트와 버전을 선택합니다. 조치 목록에서 판단이나 후속 작업이 필요한 기록을 찾습니다.

## 작업과 근거 기록

| 기록 | 작성할 내용 |
|---|---|
| 명세 | 원하는 결과, 근거, 수용 기준을 적고 관련 작업과 이슈를 연결합니다. |
| 이슈 | 관찰한 문제나 편차, 증상, 확인된 원인을 적습니다. 확인하는 대로 관찰 사례, 근거, 관련 작업을 추가합니다. |
| 작업 | 수행 단위의 담당, 목적, 성공 조건을 정합니다. 산출물을 기록하고 완료를 보고합니다. |
| 출시 기준 | 마일스톤의 Go/No-Go를 판단할 수 있는 조건을 정합니다. 판단 근거가 되는 항목을 연결하고 독립 검증 결과를 기록합니다. |

기록을 열어 관련 버전, 연결된 항목, 근거, 이력을 확인합니다. 취소한 마일스톤은 **출시 기준**에서 보관하고 필요할 때 보관 목록에서 복원합니다.

## 검색과 변경 추적

- 프로젝트와 관련 버전을 선택하고 조회 목적에 맞게 상태, 담당, 날짜를 추가합니다. 목록에는 검색 조건에 맞는 건수와 현재 페이지의 행 수가 표시됩니다.
- 날짜 컬럼 제목을 눌러 정렬 방향을 바꿉니다. 날짜 검색과 시간 표시는 브라우저의 시간대를 사용합니다.
- **이력**에서 대상, 작성자, 작업, 날짜로 변경을 찾습니다. 버전 컬럼은 대상의 현재 연결을 표시합니다. 버전이 연결되거나 해제된 시점은 개별 이력에서 확인합니다.

계획부터 독립 검증까지의 예시는 [실전 활용 가이드](workflows.ko.md), 로그인과 권한 부여는 [관리자 가이드](administration.ko.md)를 참조합니다.
